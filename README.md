# Las Profundidades de Eryndor

## 📖 Descripción
**Las Profundidades de Eryndor** es un RPG por turnos basado en pantallas y texto.  
El jugador explora una cueva legendaria, recolecta recursos, combate criaturas deformadas y descubre los secretos de una civilización perdida.  

El proyecto está desarrollado en **C++**, utilizando archivos binarios (`.dat`) para gestionar personajes, inventario, ítems y progreso.  
Es un trabajo práctico universitario con enfoque en diseño modular y arquitectura MVC.

---

## 🎮 Mecánica del Juego
- **Exploración:** pantallas estáticas con eventos, recursos y enemigos.  
- **Combate por turnos:** atacar, defender, usar objetos o huir.  
- **Inventario y crafting:** combinar materiales (madera, piedra, hierro, cristales, hongos) para crear armas y armaduras.  
- **Eventos aleatorios:** terremotos y encuentros inesperados.  
- **Progreso:** guardado en `Partidas.dat` con estado del personaje y avance en la historia.
